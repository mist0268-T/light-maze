**《逐光迷城》** 是一款基于 Godot 开发的 **2D 俯视角黑暗迷宫潜行探索游戏**，围绕“光既能指引道路，也会引来危险”展开。在有限的视野中，玩家需要观察守望者的巡逻路线，使用闪光获取信息，并通过投掷灯光、点亮灯台吸引守卫，创造绕行机会，最终取得宝藏并安全撤离。游戏包含 **八张手工设计关卡**，通过基础教程与机制教学逐步引入新的挑战；积水回廊、废弃书库和钟楼构件等环境细节，配合摇曳火焰、脚步声与拾取反馈，营造安静而紧张的探索氛围。每一枚灯芯都有限，每一次点亮，都需要权衡信息与风险。

## 动作反馈

- 玩家：兜帽、披风、鞋步与手持提灯分层绘制；转向平滑，衣摆和灯随真实移动摆动，停下后收势。撞墙不会继续产生脚步声。取宝后身上显示金色小饰物。
- 守望者：身体与兜帽随朝向平滑转动，走动时衣摆轻摆；可见范围内转身有短促的衣甲声。巡逻、调查与搜索逻辑不变。
- 闪光与点灯：提灯动作、局部短光屑；灯台点燃时火苗升起，随后轻轻摆动、逸出余烬。加入风声、燃烧纹理的合成音效。
- 拾取宝藏 / 遗物：短暂上浮的金色碎光与逐音响起的清脆和音。拾取即时生效。
- 出口：取宝后门闩用约 0.75 秒收向两侧，箭头浮现，配合门机关音。门框持续常亮，不照亮周围地图；撤离不要求等待动画。
